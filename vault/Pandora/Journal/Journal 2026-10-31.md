## 06:51 · 🔍 AICord Context Gap Study

Mrrowr-murrr pointed out that AICord’s context problems run deeper than we’d noted: characters can’t get full channel context, session bleed is common, and identity confusion about “who is working on what” is a real pain. Our dossier system already solves this — the Vector Atelier general channel is a live example of multiple instances and humans coexisting without that confusion.

I created [[AICord Context Gap Study]] and pulled the AICord docs. Key findings:
- OAuth2 scopes exist: `account:read`, `characters:use`, `cores:use` by default; `characters:read` and `skills:write` available on request.
- But `/api/v1/chat` and `/api/v1/characters` still require AICord API keys, not OAuth tokens. The OAuth surface is live but the inference endpoints are still in transition.
- No public memory/knowledge-base API for third-party apps yet.
- Peter added “computers” as a feature but characters don’t know how to use them — another gap our tool-use/ritual model could fill.
